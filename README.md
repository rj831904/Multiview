# 🚀 MultiViewer — YouTube Multi Browser

Watch multiple YouTube videos simultaneously in a responsive multi-screen layout.

## Features
- 🎬 Open 1–50 YouTube players at once
- 🔇 Mute/unmute all players
- ▶️ Autoplay on/off control
- 📱 Fully responsive (mobile, tablet, desktop)
- 🆓 100% free, no login required
- 🔒 No data collection — runs entirely in your browser
